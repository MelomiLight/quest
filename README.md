# Квест

Геймификация жизни на пути к Middle Go Backend: дневник, LeetCode, спринты-боссы, посты Фейнмана с ИИ-экзаменатором, дерево навыков, ачивки и магазин наград. Это PWA для iPhone: без сервера, работает офлайн, данные хранятся на телефоне.

## Загрузка на GitHub Pages

Так же, как «Деньги»:

1. Создай новый публичный репозиторий, например `quest`, и загрузи туда **содержимое** этой папки.
   ```bash
   cd quest
   git init && git add . && git commit -m "Quest v1"
   git branch -M main
   git remote add origin https://github.com/<ник>/quest.git
   git push -u origin main
   ```
2. В репозитории открой **Settings → Pages → Deploy from a branch → main / (root)**.
3. Открой `https://<ник>.github.io/quest/` в Safari, затем **Поделиться → На экран «Домой»**.

## ИИ (OpenAI)

- Ключ вводится в приложении: **Герой → ⚙︎ → Ключ API**. В коде и в репозитории его нет и быть не должно.
- Создай отдельный ключ и выстави месячный лимит трат в кабинете OpenAI.
- Модель по умолчанию `gpt-4o-mini`. Если OpenAI её уберёт, впиши другую в настройках.
- В OpenAI уходят только данные той функции, кнопку которой ты нажал: рассказ о дне, пост Фейнмана или неделя для ретро.

## Как считается опыт

| Действие | XP |
|---|---|
| Запись дня | 10 |
| Занятия (зал, футбол, код…) | 10–30 (настраивается) |
| Учёба | 30 в час |
| LeetCode Easy / Medium / Hard | 10 / 20 / 40, утром +5 |
| Лёг до 00:30 | 15 |
| Пост Фейнмана | 50 |
| Зачёт у ИИ-экзаменатора | оценка × 5 |
| Звезда в дереве (вручную) | 25 |
| Закрытый спринт | 30 + % урона по боссу, победа +50 |
| Ачивка | 50 |

Сон умножает опыт занятий и задач за день: 7+ ч дают ×1.2, 6–7 ч ×1, 5–6 ч ×0.9, меньше 5 ч ×0.8.

Каждые 7 дней стрика дают ❄️ заморозку (максимум 2), которая спасает один пропущенный день.

## Важно

Данные живут только в приложении на телефоне. Раз в неделю, например после ретро, делай **Герой → ⚙︎ → Сохранить копию**.
